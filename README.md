
# Icecream Sales Performance & Revenue Analysis Dashboard

## Project Overview

This project presents an interactive Sales Performance Dashboard developed using Microsoft Excel to analyze sales revenue, geographical performance, sales representatives, and overall business performance.

The project combines multiple sales and supporting datasets and transforms the raw data into meaningful business insights using data cleaning, analysis, Pivot Tables, Pivot Charts, KPIs, and visualizations.

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Analysis
- Data Visualization
- Exploratory Data Analysis

## Dashboard Analysis

The dashboard provides analysis of:

- Total Revenue
- Revenue by Country
- Revenue by City
- Revenue by Sales Representative
- Year-wise Revenue
- Geographical Performance
- Sales Performance

## Key Insights

- Germany was the strongest-performing country, contributing approximately **$65.46M (75.2%)** of total revenue.
- Frankfurt and Berlin were the top-performing cities, contributing approximately **$29.05M** and **$28.84M**, respectively.
- Ostrava recorded the lowest city-level revenue at approximately **$2.94M**, highlighting differences in market performance.
- Ellen Woody was the highest-performing sales representative, generating approximately **$28.84M**, followed by John White with **$21.72M**.
- The dashboard recorded approximately **$87.05M in total revenue**, with Germany contributing the majority of overall sales.

## Dataset

The project uses multiple datasets containing information about sales transactions, products, categories, sub-categories, geography, and sales representatives.
