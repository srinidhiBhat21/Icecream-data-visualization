# Dataset Documentation

## Overview

This folder contains the datasets used for the Sales Performance & Revenue Analysis Dashboard.

The datasets include sales transaction data along with supporting information related to products, categories, sub-categories, geographical locations, and sales representatives.

## Dataset Files

### 1. Sales Data

The sales data is divided into yearly files:

- `sales 2014.csv`
- `sales 2015.csv`
- `sales 2016.csv`
- `sales 2017.xlsx`

These files contain historical sales transaction records used to analyze revenue and sales performance over time.

### 2. Product Data

`Product.csv`

Contains product-level information used to connect sales transactions with individual products.

### 3. Categories Data

`Categories.xlsx`

Contains information about the different product categories used for classification and analysis.

### 4. Sub-Categories Data

`SubCategories.xlsx`

Contains sub-category information associated with products and categories.

### 5. Geography Data

`Geography.xlsx`

Contains geographical information such as countries and cities used for geographical sales analysis.

### 6. Sales Representative Data

`SalesRep.xlsx`

Contains information about sales representatives used to analyze individual sales performance.

## Data Relationships

The datasets are connected through common identifiers such as:

- Product ID
- Category ID
- Sub-Category ID
- Geography/Location ID
- Sales Representative ID
- Sales Date

These relationships allow the sales transaction data to be combined with supporting information for analysis.

## Data Analysis

The datasets were used to analyze:

- Total revenue
- Revenue by country
- Revenue by city
- Revenue by sales representative
- Year-wise sales performance
- Product and category performance
- Geographical performance

## Data Preparation

The data preparation process included:

1. Importing the individual datasets.
2. Reviewing and understanding the data structure.
3. Cleaning and organizing the sales data.
4. Combining yearly sales data for analysis.
5. Connecting sales data with product, category, geography, and sales representative information.
6. Creating Pivot Tables and calculated metrics for the dashboard.

## Purpose

These datasets serve as the foundation for the Sales Performance & Revenue Analysis Dashboard and demonstrate the use of multiple data sources to generate meaningful business insights.

## Note

The datasets are included for educational and portfolio purposes and are used to demonstrate data analysis, dashboard development, and business intelligence techniques.
